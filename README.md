MarkovLab Mini

Учебное веб-приложение, которое переводит вероятность из доли в проценты. Например, "0,5263" превращается в 52,63 %.

Как пользоваться

1. Откройте приложение в браузере.
2. Введите число от "0" до "1". Можно использовать запятую или точку.
3. Нажмите Перевести в проценты.

Приложение умножает введённое число на 100 и показывает результат в процентах. Если поле пустое или значение выходит за допустимый диапазон, приложение попросит исправить ввод.

Ввод| Результат
"0"| "0 %"
"0,5263"| "52,63 %"
"1"| "100 %"
"1,2"| Сообщение об ошибке

Как запустить

После публикации через GitHub Pages приложение можно открыть по ссылке из раздела Settings → Pages этого репозитория. Для запуска на компьютере можно скачать "index.html" и открыть его в браузере.

Как устроен проект

Весь код находится в файле ""index.html"" (./index.html). HTML задаёт структуру страницы, CSS оформляет интерфейс, а JavaScript проверяет ввод и выводит результат. Приложение работает прямо в браузере.# markovlab-mini.
